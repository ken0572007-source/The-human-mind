# The Human Mind — Version 2

A free, responsive psychology-learning website designed for beginners.

## What's included
- 12 psychology topics with clear explanations and reflection prompts
- Four fictional case files with evidence, answer choices, and reasoning feedback
- Five everyday scenarios to practise balanced interpretation
- Five-question psychology knowledge challenge
- Eight film recommendations with discussion prompts and context notes
- Search across topics, cases, and film titles
- Save topics and case files in the current browser
- Responsive desktop/mobile navigation
- Basic PWA manifest, icon, and offline cache support

## Preview on a computer
1. Download and extract the ZIP.
2. Open `index.html` in Chrome or Edge. Core features work locally.
3. For install/offline features, use a local server or publish it over HTTPS.

## Publish a public website with GitHub Pages (free)
You must sign in to GitHub yourself; this ZIP does not automatically create or publish an account/repository.

1. Create/sign in to a GitHub account at https://github.com/
2. Create a **new public repository** named `the-human-mind` (or another available name).
3. Upload the files from this folder (`index.html`, `manifest.json`, `sw.js`, `icon.svg`) to the repository root. Do not upload only the ZIP itself.
4. In the repository, open **Settings → Pages**.
5. Under the build/deployment section, select **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
6. Wait for GitHub Pages to finish deploying. It will show your public website address, usually:
   `https://YOUR-USERNAME.github.io/the-human-mind/`
   Replace `YOUR-USERNAME` with your GitHub username. This is a pattern, not a live link until you publish it.
7. Open that exact URL on your phone and test every page.

GitHub interface labels may change. Official guide: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## Can people find it on Google?
A public URL does not guarantee that Google will index it or show it near the top of results. After the site is live:
1. Open Google Search Console: https://search.google.com/search-console/
2. Add the exact published URL/domain and complete the ownership verification steps.
3. Use URL Inspection to request indexing for the home page.
4. Keep the page public, working on mobile, and useful. Add original content and a clear site title/description.
5. Indexing can take days or longer, and Google may decide not to index or rank a page. Do not promise anyone an immediate Google result.

## Important limitations
- This is a static, front-end website. It does not have user accounts, a database, cloud sync, or analytics.
- Saved content uses local browser storage and stays on that browser/device.
- Case files are fictional teaching scenarios, not real investigations or criminal records.
- Film descriptions are educational discussion prompts, not endorsements or clinical evidence.
- The website is educational and does not diagnose mental-health conditions.
- If you later add a custom domain, you must register it separately; it is not included here.
